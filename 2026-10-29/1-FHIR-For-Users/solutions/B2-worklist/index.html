How the list is derived from FHIR 

    
    
      
  • Being managed (PAM 6): EpisodeOfCare with status=active and type episode-type|pam.
        Patient, care manager (Practitioner) and the referral ServiceRequest come back via _include.
        "Days with team" = today − period.start.
    • 
      
  • Surgery: the waitlist ServiceRequest (category system elective-category) that the referral points to with
        supportingInfo; if there is none, the patient's active waitlist entry. Date from occurrenceDateTime
        (or occurrencePeriod.start); procedure from code; unit from the performer Organization;
        category from category.
    • 
      
  • Follow-ups: Tasks with an open status (requested, received, accepted, ready, in-progress, on-hold), matched to an
        episode by focus (EpisodeOfCare), else by for (Patient). Due date = restriction.period.end
        (what the synthetic data uses), else executionPeriod.end (what the draft mapping suggests). Overdue = due before today;
        due soon = within 7 days.
    • 
      
  • Latest Hb / ferritin: most recent Observation (LOINC 718-7 / 2276-4) per patient; flagged when below
        120/130 g/L (F/M) or 100 µg/L.
    • 
      
  • "Today" defaults to the browser's date; set it (or ?today=YYYY-MM-DD) to replay the synthetic data as of
        6 Oct 2026, the date it was generated for.
